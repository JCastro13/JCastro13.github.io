# J. Castro — Security Research & Engineering

Personal portfolio focused on **Threat Intelligence**, **Detection & Response**, and **Security Engineering**.

Published website: https://jcastro13.github.io

The site is built with React, TypeScript, Vite, and Tailwind CSS, and deployed to GitHub Pages through GitHub Actions.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deployment

Every push to `main` triggers the workflow in `.github/workflows/deploy.yml`.

In the repository settings, configure **Pages → Build and deployment → Source → GitHub Actions** if it is not already selected.

## Project integrity

Project cards are explicitly marked as planned placeholders. They will be updated only when the corresponding independent research or engineering work is completed. No employer-confidential information or unverified findings belong in this portfolio.
